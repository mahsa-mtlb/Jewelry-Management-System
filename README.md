# 💍 Jewelry Management System

A professional Jewelry Management System built with Django 5.

---

## 📌 Project Overview

This project is a complete jewelry store management system developed with Django.

It allows store managers to manage products, categories, daily gold prices, product images, and inventory through a modern Persian RTL dashboard.

---

## ✨ Features

- 🔐 Authentication
- 📊 Dashboard
- 💍 Product Management (CRUD)
- 📂 Categories Management
- 💰 Daily Gold Price Management
- 🔍 Search
- 🎯 Filters
- 🖼 Image Upload
- 📱 Responsive UI
- 🇮🇷 Persian RTL Interface
- 📅 Jalali Date Support
- ⚙ Django Admin

---

## 🛠 Technologies

- Python 3.12+
- Django 5.2

- JavaScript

## 🚀 Installation

```bash
git clone https://github.com/mahsa-mtlb/Jewelry-Management-System.git

cd Jewelry-Management-System

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate

python manage.py createsuperuser

python manage.py runserver
```
